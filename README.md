# SproutsProject

A platform for matching interns with restaurants.

## Project Setup

1. Clone the repository
2. Set up a virtual environment
3. Install dependencies
4. Run the application

## Features

- Intern registration and profiles
- Restaurant registration and profiles
- Matching algorithm
- Scheduling system
- Review and feedback

## Tech Stack

- Backend: Python (FastAPI/Flask/Django)
- Frontend: React/Vue.js (TBD)
- Database: PostgreSQL
- Authentication: JWT

## Getting Started

```bash
# Install dependencies
pip install -r requirements.txt

# Run the application
python app.py
```
