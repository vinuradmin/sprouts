♦# Sprouts Project

A web application for matching interns with restaurants for internship opportunities.

## Project Overview

This application aims to streamline the process of connecting interns with restaurant internship opportunities. It will provide features for:

- Intern registration and profile management
- Restaurant registration and internship posting
- Matching algorithm to connect interns with suitable restaurants
- Communication platform between interns and restaurants
- Application and interview management

## Project Structure

```
SproutsProject/
├── app/                    # Main application package
│   ├── models/            # Database models
│   ├── services/          # Business logic
│   ├── templates/         # HTML templates
│   └── static/            # Static files (CSS, JS, images)
├── tests/                 # Test files
└── docs/                  # Documentation
```

## Getting Started

### Prerequisites

- Python 3.8+
- pip (Python package manager)

### Installation

1. Clone the repository (once Git is set up)
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Set up environment variables (create a .env file based on .env.example)
4. Run the application:
   ```
   python run.py
   ```

## Features

- **Intern Profiles**: Create and manage intern profiles with skills and preferences
- **Restaurant Listings**: Restaurants can post internship opportunities
- **Smart Matching**: Algorithm to match interns with suitable restaurants
- **Application Tracking**: Track application status and communications
